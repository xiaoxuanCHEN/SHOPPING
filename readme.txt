# SHOPPING —— 仿小米商城 Java Web 项目

## 1. 项目简介

SHOPPING 是一个基于传统 Java Web 技术开发的在线商城项目，参考小米官方商城的业务形态实现，主要用于学习和演示基础电商网站的开发流程。

项目围绕用户购物这一核心场景，覆盖用户注册与登录、商品及分类管理、商品浏览、购物车、订单、订单详情和商品评论等基础功能，同时包含面向管理端的页面与业务处理代码。

本项目采用 Servlet + JSP 的经典分层开发方式，适合作为 Java Web、JDBC、DAO/Service 分层以及基础电商业务流程的学习示例。它是一个较早期的课程/练习型项目，并非可直接部署到生产环境的现代电商平台。

## 2. 主要功能

### 用户端

- **用户注册与登录**：提供用户注册、登录及用户信息编辑相关处理。
- **商品浏览**：支持商品列表展示、商品详情及商品图片相关请求。
- **商品分类**：按商品类别组织和展示商品。
- **购物车**：查看购物车商品、调整商品数量、移除商品、清空购物车及进入结算流程。
- **订单管理**：提供订单创建/查询及订单详情相关处理。
- **商品评论**：提供商品评论的新增、查询及管理相关处理。

### 管理端

- **商品管理**：商品新增、修改、删除、查询及分页处理。
- **分类管理**：商品分类新增、编辑、删除和列表查询。
- **评论管理**：评论查询、编辑、删除及分页处理。
- 项目包含独立的管理端页面目录，具体可用操作以当前代码实现为准。

## 4. 项目结构

项目采用经典 Java Web 分层结构，主要代码包如下：

```text
SHOPPING/
├── src/
│   └── xm/chen/
│       ├── controller/    # Servlet 控制器，接收和处理 HTTP 请求
│       ├── service/       # 业务逻辑接口
│       ├── service/impl/  # 业务逻辑实现
│       ├── dao/           # 数据访问接口
│       ├── dao/impl/      # DAO 实现，负责 JDBC 数据库操作
│       └── modal/         # 项目实体/数据模型类（原项目目录命名）
├── WebRoot/
│   ├── user/              # 用户端页面
│   ├── admin/             # 管理端页面
│   ├── common/            # 公共页面资源
│   ├── css/               # 样式文件
│   ├── js/                # JavaScript 文件
│   ├── images/            # 图片资源
│   └── WEB-INF/           # Web 配置及相关资源
└── readme.txt
```

> 以上为主要目录说明，实际文件和目录以仓库当前内容为准。

## 5. 核心业务流程

### 购物流程

1. 用户注册或登录商城。
2. 浏览商品分类和商品列表。
3. 查看商品信息并将商品加入购物车。
4. 在购物车中调整商品数量或移除商品。
5. 提交结算，进入订单处理流程。
6. 查看订单及订单详情，并可使用项目提供的评论功能。

### 典型分层调用关系

```text
Browser
   |
   v
JSP 页面 / Servlet Controller
   |
   v
Service 业务层
   |
   v
DAO 数据访问层
   |
   v
JDBC + DBCP
   |
   v
Microsoft SQL Server
```

## 6. 运行环境与配置说明

项目原始配置基于较早期的 Java Web 开发环境。运行或二次开发前，建议检查并按本机环境调整以下内容：

1. 安装并配置兼容项目的 JDK。
2. 配置支持 Servlet 3.0 的 Java Web 容器（例如相应版本的 Tomcat）。
3. 准备 Microsoft SQL Server 数据库。
4. 检查数据库连接配置、数据库名称、账号及密码，并替换为本地有效配置。
5. 在 IDE 中导入 Web 项目，检查项目 Facet、JDK、Servlet/JSTL 依赖及部署配置。
6. 部署到 Web 容器后，通过浏览器访问项目。

仓库当前 README 未提供完整的数据库建表脚本和初始化数据说明，因此首次运行前还需要结合项目 SQL/数据库文件及代码中的表结构要求准备数据库。

## 7. 当前项目的技术特点与注意事项

- 项目采用 Servlet/JSP 传统开发模式，没有使用 Spring Boot、Spring MVC 等现代应用框架。
- 数据访问主要通过 JDBC 和 DAO 实现，便于学习 SQL、PreparedStatement 和基础分层设计。
- 原始工程配置使用 Java 6、较旧版本的 jQuery 和 MyEclipse，直接在新版本 JDK 或容器中运行时可能需要调整依赖及兼容性配置。
- 数据库连接信息应放在本地配置或环境变量中，不应将真实账号、密码提交到代码仓库。
- 数据库查询应使用参数化 SQL，避免通过字符串拼接外部输入构造查询条件。
- 数据库连接、Statement 和 ResultSet 应使用方法级局部资源并确保及时关闭，避免在并发请求间共享 JDBC 对象。
- 正式部署前还应补充登录鉴权、权限校验、输入校验、密码安全存储、异常处理、日志记录及安全测试。

## 8. 项目定位

本项目适合：

- 学习 Java Servlet、JSP 和传统 Java Web 项目结构。
- 理解 Controller、Service、DAO 的基本分层方式。
- 熟悉 JDBC、SQL Server 和连接池的基础使用。
- 了解商品、购物车、订单、评论等基础电商业务流程。
- 作为老项目维护、代码审查或现代化重构的练习对象。

**说明：** 本项目是学习性质的基础商城示例。README 中列出的功能是根据仓库现有代码结构整理的概述，具体页面行为和业务完整度请以实际代码为准。
